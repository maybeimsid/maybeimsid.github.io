About me

If you have a minute.

I have a software engineering background. The core of it was at Amazon Web Services, where I built distributed systems for AWS Systems Manager: a Change Tracking microservice using event-driven architecture (DynamoDB, SNS, SQS), backend APIs with full auth and integration test coverage, and multi-region expansion automation that cut launch timelines from weeks to hours. The systems I worked on were used by tens of thousands of enterprise customers globally, BMW and Intercom among them. I owned services end to end: design, deployment, on-call rotation.

I went back to school to do a Master of Data Science at UBC, building on an M.S. in Computer Science from UT Arlington. The MDS has added statistical thinking, machine learning, and the full ML stack to the engineering background. The goal being to actually understand the models, not just call the API.

My capstone was with Educational Testing Service (makers of the SAT, GRE, and TOEFL): an equity-focused PISA analysis pipeline across 81 countries and 29 million students. Weighted OECD estimation with IRT plausible values, auto-generated plain-language chart summaries, deployed as a Streamlit dashboard with pytest and GitHub Actions CI/CD. Not every project has a line between the technical work and a real decision someone makes. This one did.

Other recent projects: a hybrid RAG system over 700k+ Amazon product reviews fusing BM25 sparse retrieval with FAISS dense search via Reciprocal Rank Fusion -- Llama 3.2 via Ollama, about 8x faster than exact vector search, every answer source-attributed. And a Shiny for Python housing dashboard with live Mapbox filtering and Anthropic API integration, deployed on Posit Connect Cloud.

I want to work on systems where correctness and reliability matter. Open to software engineering, ML engineering, and data science roles.
