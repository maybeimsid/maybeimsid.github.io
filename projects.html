PISA Equity Dashboard

Built for Educational Testing Service (ETS), the organization behind the SAT and GRE. A full analytical pipeline surfacing education equity patterns across 81 countries and 29 million PISA students, with automated policy narrative generation.

Python Streamlit DuckDB Parquet GitHub Actions LLM
GitHub Live App
Key details
Weighted OECD estimation pipeline with IRT plausible values across 81 countries and 29M students
LLM integration (Claude API) for automated country-level and indicator-level policy narrative generation
Parquet + DuckDB backend for sub-second filtering across the full PISA dataset without a server
CI/CD via GitHub Actions: data validation, regression tests, and Streamlit Cloud deployment on every push
Commissioned by ETS as a real research deliverable, not a course exercise
